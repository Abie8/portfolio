# Abishek S — Data Analyst Portfolio

A responsive single-page portfolio built with HTML, CSS and JavaScript.

## Projects
- LinkedIn Data Analysis
- Starbucks Data Analysis
- Hospital Admission Dashboard

## Publish on GitHub Pages
1. Create a repository named `portfolio` (or any name) on GitHub.
2. Upload `index.html`, `style.css`, and `script.js`.
3. If you have a resume PDF, upload it as `resume.pdf`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your site will be available at the GitHub Pages URL shown there.

## Before publishing
Replace `your.email@example.com` in `index.html` with your actual email.
Update each project link from your GitHub profile URL to the specific repository when those repositories are ready.
